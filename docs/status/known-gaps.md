# Known gaps

- Phase 0 is complete and the local durable-core implementation is in progress;
  no deployable Coordinator, worker service unit, provider launcher, or
  remote-access implementation exists yet.
- RustDesk is represented only as a constrained architecture contract; there is no relay deployment, endpoint, enrollment, or credential material.
- Durable-core unit and database fixtures are being added; worker, provider,
  attention, and end-to-end fixtures remain future work.
- The public repository intentionally omits private source specifications, fleet inventory, network topology, and secret references beyond generic examples.
